# Screenshot-inspired UI mapping

The two uploaded screenshots were used as the visual reference.

1. `home.ejs` reproduces the structure:
   - header/logo area
   - service navigation bar
   - security warning
   - announcement strip
   - Personal Banking and Corporate Banking panels
   - login buttons
   - quick links

2. `login.ejs` reproduces the structure:
   - purple/white banking header
   - Personal Banking navigation
   - large Hello/welcome section
   - Register Now / Activate Username
   - Username / Password card
   - Forgot Username / Password links
   - CAPTCHA-style field
   - Login button

Branding is intentionally changed to SecureBank. This is a training implementation and is not SBI software.
